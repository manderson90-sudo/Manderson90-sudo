# Michael Anderson | Technology Leadership

A static, GitHub Pages-ready rebuild of the Base44 portfolio. Built with plain HTML, CSS and JavaScript, so no hosting subscription or build tools are required.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example `michael-anderson-portfolio`).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the root of the repository.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will show the published website URL after deployment.

## Edit content
- `index.html`: all site copy, career history, achievements, qualifications, navigation and links.
- `styles.css`: colours, fonts, spacing, cards and mobile layouts.
- `script.js`: navigation and recommendation carousel. Add additional verified recommendations to the `recommendations` array.
- `assets/profile.jpg`: profile image.
- `assets/Michael-Anderson-CV.docx`: downloadable CV.
